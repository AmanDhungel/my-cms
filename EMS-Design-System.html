EMS colour & style guide

A warm, low-strain palette for a system people check in on all day — soft neutral surfaces for the long dashboard sessions, a confident teal for trust and direction, and marigold reserved for the moments that need a hand raised. Click any swatch to copy its hex.

Primary — petrol teal

Brand colour, primary buttons, links, active navigation, focus rings. Deliberately deeper than a typical SaaS blue — reads as steady and trustworthy rather than loud.

Main: #0E7C7B (500)

Accent — marigold

Used sparingly: primary CTAs, unread badges, "this needs you" moments. If more than one thing on screen is marigold, something else should probably be quieter.

Main: #E89A1C (400) for fills · #A3660A (600) for text on light backgrounds

Neutral — warm grey

Backgrounds and text. A warm off-white page (#FAF9F7) instead of pure white, and a soft near-black for text instead of pure black — the pairing that actually reduces eye strain on a screen someone stares at all day, versus a stark black-on-white dashboard.

Page background: #FAF9F7 (50) · Body text: #1B1815 (900)

Status — task lifecycle

One colour per state, matched to your workflow. Colour is always paired with a text label — never colour alone — so it still reads correctly for colour-blind users.

Typography

Sora for headings — geometric and confident without tipping into decorative. Inter for everything else — it stays legible at the small sizes a dense dashboard needs. JetBrains Mono for anything that's really data: timestamps, coordinates, task IDs.

Principles

Colour is small, not loud

Saturated colour lives in buttons, badges, and dots. Large surfaces — cards, backgrounds, panels — stay in the neutral 50–100 range so nothing fatigues the eye over a full shift.

Never colour alone

Every status dot ships with a text label. It has to work for a colour-blind supervisor glancing at a phone screen in bright sunlight.

Warm, not stark

No pure #FFFFFF backgrounds, no pure #000000 text. The warm-grey scale keeps contrast high without the glare of true black-on-white.

Marigold is a request, not decoration

If it's marigold, it means someone needs to act. Don't spend the accent colour on things that are just informative.

Implementation

Drop straight into globals.css.

:root {
  --p-500: #0E7C7B;  /* primary */
  --p-600: #0B6362;  /* primary hover */
  --p-100: #CFEDEA;  /* primary tint */
  --a-400: #E89A1C;  /* accent */
  --a-600: #A3660A;  /* accent text-on-light */
  --n-50:  #FAF9F7;  /* page background */
  --n-900: #1B1815;  /* body text */
  --n-200: #E4E1DA;  /* borders */

  --status-material: #E8A317;
